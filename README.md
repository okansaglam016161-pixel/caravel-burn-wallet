# Caravel Burn Wallet

> **Testnet only. Work in progress.** No template code yet.

A Tari Ootle template for a **deposit-only** wallet:

- **Deposit only.** Anyone can send TARI in. Nothing can ever be taken out.
- **No owner.** No admin key, no withdraw method, no upgrade path.
- **Locked forever.** TARI deposited here leaves circulation permanently.
- **Public balance.** The total held is readable by anyone, on-chain.

Part of [Caravel](https://github.com/okansaglam016161-pixel/caravel), alongside
[Caravel Lotto](https://github.com/okansaglam016161-pixel/caravel-lotto).
